# дело. — статичный маркетплейс услуг

Красивый адаптивный сайт на обычных **HTML + CSS + JavaScript**, который можно разместить на **GitHub Pages**. Сборка, Node.js, платный хостинг, токены и внешняя база данных не нужны.

## Функции

- Каталог с 8 явно помеченными демонстрационными объявлениями.
- Поиск, категории, сортировка по цене/названию/дате и избранное.
- Публикация своей услуги: обложка, название, категория, описание, стоимость, город, имя и контакты.
- Автоматическое уменьшение загруженных JPG/PNG/WebP перед сохранением.
- Карточка услуги с подробным описанием и кнопками для связи через Telegram, WhatsApp, e-mail. **Оплаты на сайте нет**: клиент договаривается и оплачивает напрямую исполнителю.
- Админ-панель: удаление/скрытие объявлений, восстановление примеров, экспорт и импорт JSON.
- Плавные анимации, мобильная версия, нет зависимостей от JS-фреймворков.
- Иллюстрации расположены в `assets/` и работают без интернета. Внешний Google Fonts используется только для необязательного шрифта Manrope: при его недоступности будет системный шрифт.

## Публикация на GitHub Pages

1. Создайте **публичный репозиторий** на GitHub (например, `delo-market`).
2. Загрузите **содержимое этой папки в корень репозитория** — `index.html`, `app.js`, `styles.css`, папку `assets/` и `README.md`.
3. На GitHub откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, затем нажмите **Save**.
5. После публикации сайт будет доступен по адресу вида `https://USERNAME.github.io/delo-market/`.

Также можно открыть `index.html` напрямую для просмотра дизайна, но для корректной работы браузерного хранилища и проверки админ-пароля используйте GitHub Pages (HTTPS) или локальный сервер, например:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Где находится админ-панель?

Ссылка **«Админ-панель»** в самом низу сайта. Пароль был передан отдельно при заказе сайта; **его открытого текста нет в репозитории**. В `app.js` хранится только результат PBKDF2-SHA256 с индивидуальной солью и 210 000 итераций.

**Внимание:** эта схема не обеспечивает настоящую авторизацию! В полностью статическом проекте код проверки работает у посетителя, и технически подготовленный человек может обойти проверку, изменив JavaScript через инструменты разработчика. Для защиты данных всех пользователей нужен серверный API и настоящая авторизация.

## Где хранятся услуги?

В `localStorage` браузера на конкретном устройстве. **Это демо-режим, а не общедоступная база:**

- новые публикации видны только в браузере, в котором они созданы;
- удаление администратором влияет только на тот же браузер;
- браузер может удалить локальные данные, особенно при очистке хранилища;
- фото сохраняются вместе с объявлениями и упираются в ограничение `localStorage` (обычно несколько мегабайт);
- экспорт JSON в админке сохраняет резервную копию локальных публикаций; импорт позволяет восстановить её в другом браузере вручную.

Восемь примеров являются **демонстрационными**, их контакты `demo@example.com` не принадлежат реальным исполнителям. Их можно отредактировать в массиве `DEMO_SERVICES` файла `app.js`. Технически эти карточки включены во все опубликованные версии GitHub Pages и доступны всем, пока не будут изменены в репозитории.

### Если понадобится реальный общий каталог

GitHub Pages можно оставить для **фронтенда**, но для публикаций, которые видны всем, и надёжного администрирования понадобится внешнее хранилище и авторизация — например, **Supabase** (PostgreSQL + Auth + Storage + RLS), **Firebase** или отдельный API. Пароль и административные права необходимо проверять **на серверной стороне**, а доступ на запись/удаление ограничивать политиками безопасности. Не кладите секреты, service-role keys или GitHub access tokens в код фронтенда.

## Структура проекта

```text
delo-market/
├── index.html         # разметка каталога, карточек, модальных окон
├── styles.css         # стиль, анимации, адаптивность
├── app.js             # каталог, форма, localStorage, админ-панель
├── assets/            # авторские SVG-обложки и favicon
└── README.md          # установка и ограничения
```

### Как изменить оформление

В `styles.css` наверху есть переменные `--ink`, `--paper`, `--lime`, `--muted`. Название и тексты меняются в `index.html`.
